## Что изучено

3. Познакомился с полиморфизмом

## Ответы на вопросы

1. *Абстрактный класс* - это шаблон для других классов. `Character()` нельзя создать напрямую, потому что это ***общий шаблон*** персонажа

2. `super` вызывает *конструктор родителя*. Если его убрать, **Dart** не сможет правильно создать персонажа, если обязательные параметры родителя не будут переданы

3. `attack()` задаёт собственный *урон воина*, а `takeDamage()` изменяет *получение урона*

4. **Полиморфизм**. Во *Flutter* похожий принцип используется с классом `Widget`, от которого наследуются разные виджеты

5. `_` означает, что переменная приватная и доступна только внутри своей библиотеки
